首页是统一人生实验台，保持 GitHub Pages `main /根目录` 发布方式。完全静态，无真实 AI 或后端。

## 本轮闭环修复

普通解释、可点击人物卡、多阶段终局、离乡真实状态、持续问题与冷却已接入。新增必须等待玩家的家庭决策，以及每3个月的主动窗口。详见 [闭环审计与边界](./CLOSURE_AUDIT.md)。

## V2 使用

1. 测试中心选择现代/古代、模板、seed、初始资源与状态。新建固定案例、组合测试或连续人生。
2. 模拟页面逐月推进，普通月份在年度内单独折叠。默认行为不经过概率决策；冲突、异常和机会才进入共享概率引擎。
3. 主动安排可普通推动或强制当前安排；强制不能突破资源、健康、年龄或对方不参与。预设提供一枚测试强制机会，也可用完成三个愿望的测试输入获得。
4. 婚配显示双方与家庭的反应；`TC-FORCED-24M` 本版可用 seed 5。若指定 seed 下对方拒绝或仍在议亲，会明确显示，不能伪造成功。
5. 死亡后接班和个人遗产分配分别等待玩家选择。个人遗产60/40，家庭共同资源不参与。
6. 每条月份/重要结果可保存合理、问题、很好的结果。反馈记录中筛选、导出、导入、按原初始状态与命令序列重放。版本不兼容会明确拒绝重放。

V2 使用独立 IndexedDB `pea-mock-v2` 保存运行和反馈。旧版 localStorage 保持独立，旧入口为 [legacy.html](./legacy.html)。未把旧版不同结构存档静默迁移成 V2。

## 模块与检查

- `src/core`：统一月份、seeded RNG、状态、命令和月循环。
- `src/systems`：人物生成、遗传、家庭、专业状态、资源、关系婚姻、生育、长期状态、默认行为、事件、干预、死亡、接班与继承。
- `src/testing`：原14个固定案例及7个玩家决策案例、8个系统组合、共享 Behavior Lab、Genetics Lab、运行/反馈持久化和重放。
- `src/config`：冻结版本元数据、集中 MOCK_TUNABLE 参数、两个世界的小型数据集、MOCK_ONLY 外貌特征池。
- `decisions.js`：V1/V2 共用事件候选、可行性、log-weight/softmax 和整数概率抽样。V2 增加专业系统约束与可传入临时配置；旧版默认参数不变。

核心测试：`node tests/v2.cjs`。旧版回归：`node test-worlds.cjs`、`node test-behavior-lab.cjs`。

手机自动化：使用已安装的 Playwright，启动任意静态 HTTP 服务后运行 `node tests/mobile.cjs`，可通过 `TEST_URL` 指定页面。只用于开发测试，不属于网页运行依赖。

### 临时规则与已知边界

工资、生活成本、教育时长、健康恢复/衰老、事件频率、关系态度/强度、婚配年龄/成本、家庭意见代表、职业样例及技能成长是 Mock 假设。设置面板仅改变新运行的配置，不更改已有记录或设计文件。

五官/颜色资源除四个正式肤色 ID 外使用 MOCK_ONLY 池，暂无真实美术显示。当前婚配联系人场景以不同性别对象测试生育链；接班两代旁系暂解释为兄弟姐妹及其子女，需要继续观察。婚后暂迁入提议者家庭，不转移对方家庭共同财富；暂时疏离使用临时居住长期状态，尚不实现完整分家、离婚和地理迁徙。

长运行按月保存审计事实，去除月日志中重复的早年经历；反馈创建时从初始状态及命令重建完整前后现场。长运行/大量反馈仍会增加设备存储使用，请定期导出。没有服务端同步。

这是人物模拟测试器的独立公开静态版本，只用于 Mock 规则测试。

- 完全在浏览器中运行，不依赖 Python 后端或真实 AI。

## 双世界测试

顶部选择 **现代** 或 **古代**。两边共用概率决策流程，古代仍采用不绑定朝代的前工业农业社会设定；身份、有限教育、路费与家庭责任作为现实条件参与判断。页面一直显示 `STATIC MOCK MODE`。

- 两个世界分别保存人物、月份、月度日志、评价、候选事件、同情境对比和跨世界对比历史。
- 每边都支持随机人物 / 婴儿、推进1 / 3 / 12个月、5～20人同情境对比。
- “同人物跨世界”使用相同人物快照和共同抽象情境，展示两种背景下的候选概率、抽样结果和理由。两边共用随机种子与抽样分位，事件决定各自扰动幅度；不执行成长或推进时间。
- 跨世界结果以一组独立历史存于发起世界，不写入另一个世界。每边结果都可评价或加入带世界标记的候选事件。
- 完整导出只包含**当前世界**，包括它发起的跨世界对比。需要迁移两边时，请分别导出两份。导入要求当前所选世界与存档一致；清空仅影响当前世界。
- 旧版浏览器存档自动归入现代，旧 key 保留原始副本；旧版导出也只能导入现代。

保存 key 为 `modern_pea_character_sim_static_v1` / `ancient_pea_character_sim_static_v1`。浏览器之间不共享数据。

## 临时规则 / TODO

世界规则集中在 `worlds.js` 的 `WORLD_CONFIGS`：允许 / 禁用背景、身份、事件方向、兴趣样例、约束权重和目标解释。人物属性量尺与技能成长公式共用。

- 古代事件来自有限的年龄 / 身份筛选模板；自由情境只作简单关键词分类，尚不理解任意自然语言。婚配、生育、疾病、征役、资产等只讨论情境，不更新对应系统状态。
- 出行、教育、身份引介、家庭责任、性别机会成本及其分值均为可替换的测试假设，不代表所有前工业社会。性别成本只用于部分外出 / 学习机会，不影响天赋、技能上限或禁止某个性别生成身份。
- 古代输入和生成结果会检查禁用词。词表可以阻止列出的时代错位内容，但不是完整的语义时代检测器；新发现的错位需要补充词表或模板规则。
- 跨世界不改原始属性：只在事件与兴趣领域匹配时修正参与概率，未知兴趣默认不匹配。无法沿用的身份按年龄解释为普通农户或现代学生 / 无业，不推断人物拥有土地、师资或亲属。
- 抽象发展机会暂对应现代适龄兴趣体验、古代远集邀约 / 作坊试学，用于检验约束差异，不是完整的人生机会分配模型。旧经历保留在相同输入快照中，跨世界不直接续写另一个时代的经历。
- 统一年月标尺从2026年开始，仅供月份和年龄计算，不是古代历史纪年。
- 目标加权随机、兴趣到技能的样例映射和技能增量公式仍为临时规则；没有正式职业、经济、婚姻或世界模拟系统。
- 人生目标只在事件或行为含有明确长期方向标签时修正概率权重：`unrelated = 0`、`indirect = 0.2`、`direct = 1.0`。旧相关性配置保留，旧分值转换为有上限的权重修正；无明确标签默认无关。

## 概率决策

`decisions.js` 集中定义行为特征、模板、可行性、修正上限和随机参数。候选行为不接收性格、兴趣、目标或天赋。

1. `generateCandidateActions(event, context)` 从事件领域生成回应及0～1行为特征。
2. `filterFeasibleActions(...)` 排除重病外出、无人替班时离开照护、时间不足、未确认长期条件直接承诺等行为；被排除项记录0%。
3. `calculateActionProbabilities(...)` 合并基础权重、现实条件、有上限的属性修正和事件相关扰动，用 softmax 归一化。
4. `sampleAction(...)` 按概率区间抽取，允许选中非最高概率行为。

每个候选行为记录 `traits`、`action_tags`、`modifiers`、`probability` 和 `probability_units`。概率以0.1%为单位，用最大余数法保证合计100%；实际抽样使用同一组整数份额。日志保存候选原貌、被排除行为及原因、现实条件、稳定性、seed和抽样分位，可复现判断。

参数是**对数权重**，不代表百分点：单个性格维度最多±0.35，性格合计±0.8；匹配兴趣最多+0.45，人生目标最多±0.5，相关挑战中的天赋最多±0.15。思考/情感仅在资源或关系权衡中参与，计划性在普通短事中弱、紧急延迟上为0，天赋不参与普通社交。单项属性不能独自锁定结果；现实约束仅剩一项可行行为时则可出现100%。

随机性包含事件相关的三角扰动、温度和最终加权抽样。稳定性：普通日常0.2、兴趣娱乐0.35、社交0.5、学习0.6、长期选择0.9、安全/健康0.95、紧急0.98。扰动幅度为 `0.6 × (1 − 稳定性)`，温度为 `1 + 0.65 × (1 − 稳定性)`；重大选择扰动更小，但仍按分布抽样。

现实条件下拉框只设置当前世界的测试假设，作用于后续月度和对比；也可由自定义事件的 `conditions` 结构提供事实，不增加人物健康字段。条件只做有限词句识别，不具备通用自然语言理解。当前保留领域级Mock行为模板，尚无正式事件库。只有实际选择事件提供的练习才产生技能建议，拒绝、核实或等待不会凭空练习最高兴趣。

旧日志继续保留历史评分及结果；页面明确标为历史，不重算成概率。存档格式及两个世界的保存位置不变。

## 行为权重实验室

点击主页面的“行为权重实验室”，或打开页面的 `#behavior-lab` 链接。实验世界和人物模板独立于主模拟器，设置与结果仅放内存，不修改存档。主模拟器的权重参数保持不变。

- 现代/古代各7个固定语义事件；3种固定人物模板；四维性格、五项天赋、指定领域兴趣扫描，以及四种人生目标类别对比。
- 默认每10点扫描，精细模式每5点。曲线、概率表、单点滑块及详细计算共用正式 `calculateActionProbabilities`；输入恒定 `rng = () => 0.5` 将扰动置零，保留事件温度。固定人物30岁、男性；现实条件明确允许出行、长期条款已核实，具体快照可展开查看。
- 一键实验：计划性、兴趣、外向、无关性、长期决定。兴趣可指定音乐检验与治安无关；事件没有匹配领域时不造一个相关兴趣。
- 独立随机预览不改理论曲线；100/1000/10000次抽样共用正式 `sampleAction`，按当前无扰动分布分批执行，每250次让出主线程。更改输入会取消旧批次并清除旧结果。
- 健康检查只报警不优化：合计100%、选项固定、最高概率85%、端点最大变化不足3个百分点、相邻变化折算每10点超过5个百分点、相关/无关兴趣和确认行为单调性。阈值是诊断假设，取整允许小阶梯；四类目标没有连续曲线跳变检查。
- 当前中性音乐事件：计划性端点最大变化仅1.8个百分点，报告偏弱；音乐兴趣使参与总概率60%→65.2%。未被某事件使用的天赋出现水平线是预期现象。长期发展事件中部分天赋也未接入选择判断，实验室如实显示0，不补规则。

实验检查：`node test-behavior-lab.cjs`，覆盖154组细扫、共享核心一致性、健康报警和10000次固定种子抽样。无图表依赖或远程CDN。
